## 🌐 Tachyon Express Installer v1.7.0: Fleet Manager & Batch Deployment

Крупное обновление установщика Tachyon с функционалом централизованного управления парком роутеров (**Fleet Manager**), автоматическим аудитом сетевых устройств и исправлением интерфейса.

---

### 🚀 Ключевые нововведения v1.7.0

#### 1. 🌐 Менеджер флота роутеров (Fleet Manager)
Теперь Tachyon Installer умеет автоматически находить поддерживаемые роутеры в локальной сети, проводить их полный аудит и выполнять массовую параллельную установку или обновление:
- **Автопоиск в локальных подсетях**: сканирование заданных диапазонов CIDR (`192.168.1.0/24`, `10.0.0.0/24` и др.) или автоматическое определение активных IPv4-интерфейсов ПК.
- **Аппаратный аудит устройств**: быстрое определение модели роутера, архитектуры процессора (MIPS, ARMv7, AArch64, x86_64), объема доступной оперативной памяти и свободного места на флеш-накопителе.
- **Аудит состояния Tachyon**: мгновенное распознавание статуса каждого устройства:
  - `[АКТУАЛЕН]` — Tachyon уже установлен и работает на актуальной версии.
  - `[УСТАРЕЛ]` — установлена предыдущая версия, требуется обновление.
  - `[ЧИСТЫЙ]` — роутер доступен по SSH, Tachyon еще не развернут.
  - `[МАЛО ПАМЯТИ]` — на устройстве критически мало RAM или Flash (выдается предупреждение).
  - `[ОШИБКА ВХОДА]` — требуется указать пароль учетной записи.
- **Интеллектуальный подбор движка**: автоматический выбор ультралегкого ядра `steer` для роутеров с объемом RAM < 64 МБ и производительного `sing-box-lx` для роутеров с RAM ≥ 64 МБ.
- **Пакетное кэширование загрузок**: если в сети находится несколько роутеров одной аппаратной платформы, установочный пакет скачивается из интернета ровно один раз, после чего параллельно деплоится на все узлы с минимальным трафиком.

#### 2. 🖥 Интерактивный TUI-дашборд
Управлять флотом можно прямо из красивого консольного интерфейса:
- Быстрый переход: кнопка **`🌐 Флот роутеров`** на шаге подключения или горячая клавиша **`F`**.
- Таблица устройств с интерактивными чекбоксами `[✓]`.
- Удобные горячие клавиши:
  - `Space` — переключить выбор для текущего роутера.
  - `A` — выбрать **все** обнаруженные устройства.
  - `U` — выбрать только те, где Tachyon **устарел**.
  - `C` — выбрать только **чистые** роутеры.
  - `S` — повторное сканирование сети.
  - `Enter` — запуск параллельного деплоя с живым логом и индикаторами прогресса.
  - `Esc` — возврат в главное меню мастера установки.

#### 3. ⚙️ CLI-автоматизация для серверов и скриптов
Для системных администраторов и автоматизации добавлены флаги командной строки:
- `-fleet-scan` — сканирование сети и печать структурированной ASCII-таблицы состояния парка устройств.
- `-fleet-deploy` — пакетное развертывание Tachyon на выбранные роутеры.
- `-fleet-subnets="192.168.1.0/24,192.168.8.0/24"` — указание целевых подсетей для сканирования.
- `-fleet-only-outdated` — деплой только на роутеры с устаревшей версией Tachyon.
- `-fleet-only-clean` — первоначальная установка только на чистые роутеры.
- `-fleet-concurrency=N` — настройка параллелизма воркеров развертывания (по умолчанию 5).

#### 4. 🛠 Исправления и полировка интерфейса
- **Исправление бага с невидимым текстом**: устранен баг рендеринга в TUI Setup Wizard / Autopilot, когда текст пунктов меню становился невидимым на некоторых эмуляторах терминалов до нажатия стрелок навигации.
- Оптимизированы таймауты SSH-пробинга для быстрого обнаружения устройств даже при высокой задержке в Wi-Fi сети.

### 📦 Доступные сборки:
- **Windows**: `tachyon-installer-windows-amd64.exe` (x86_64), `tachyon-installer-windows-arm64.exe` (ARM64)
- **Linux**: `tachyon-installer-linux-amd64` (x86_64), `tachyon-installer-linux-arm64` (ARM64)
- **macOS**: `tachyon-installer-darwin-arm64` (Apple Silicon M1/M2/M3/M4), `tachyon-installer-darwin-amd64` (Intel)
- **Контрольные суммы**: `sha256sums.txt`
