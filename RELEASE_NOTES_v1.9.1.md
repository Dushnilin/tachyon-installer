## ⚡ Tachyon Express Installer v1.9.1: Hotfix двойного нажатия клавиш на Windows

Срочное обновление установщика Tachyon, полностью устраняющее критическую проблему «двойного нажатия клавиш» на Windows (задваивание символов в полях ввода, пропуск шага ввода пароля по Enter и дублирование команд в меню).

---

### 🐛 Причина проблемы и что исправлено

#### 1. 🛑 Устранение корня проблемы в библиотеке терминала (`tcell`)
- **Баг в `tcell v2.13.9`**: В свежих версиях библиотеки `tcell` драйвер консоли Windows (`tty_win.go`) считывал события через `ReadConsoleInputW` без проверки флага `bKeyDown`. В результате каждое нажатие клавиши генерировало **два** события: сначала на нажатие (Key Down), а затем повторно на отпускание (Key Up). По этой причине вводимые символы удваивались (`1` -> `11`), а нажатие Enter на шаге ввода IP немедленно отправляло Enter на шаг ввода пароля и скипало его с пустым паролем.
- **Закрепление стабильной версии `tcell/v2 v2.8.1`**: Зависимость закреплена за эталонной версией `v2.8.1` (используемой самой библиотекой `tview`), где обработчик консоли Windows (`console_win.go`) гарантированно игнорирует события отпускания клавиш (`if isdown == 0 { return }`).

---

#### 2. 🛡️ Защита от случайного пропуска шага ввода пароля (Debounce Guard)
- В пошаговый мастер добавлена защита от пробития Enter: при переходе со 2-го шага (IP роутера) на 3-й шаг (ввод пароля) активируется защитный таймер на 200 мс. Даже при случайном двойном клике или зажатии Enter шаг ввода пароля гарантированно не будет пропущен.

---

#### 3. ⌨️ Глобальный фильтр дребезга ввода на уровне приложения
- В цикле событий `main.go` настроен `app.SetInputCapture` с фильтрацией моментальных дубликатов идентичных клавиш, приходящих быстрее 35 мс (защита от дребезга механических клавиатур и багов эмуляторов терминалов MinTTY / ConPTY).
